# Workflow 1: Telegram Bot to OpenAI

## Deskripsi

Workflow ini menghubungkan Telegram Bot dengan OpenAI untuk menjawab pertanyaan user secara otomatis.

## Komponen

- **Telegram Trigger**: Menerima pesan dari user
- **AI Agent (OpenAI)**: Memproses pertanyaan dan generate jawaban
- **Telegram Send Message**: Mengirim jawaban kembali ke user

## Setup

1. Buat bot di BotFather
2. Dapatkan Bot Token
3. Dapatkan OpenAI API Key
4. Import workflow JSON ke n8n
5. Configure credentials
6. Activate workflow
